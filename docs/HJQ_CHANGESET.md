# hjq 提交范围与资源清理

本分支汇总当前客户端代码、随附资源、离线准备工具、测试和文档改动，并向 `lulunomaro/polar-rm-client` 的 `main` 提交。

## 功能封装

- `rm_client/ui/endfield/`：终端 Wiki、原生 Esc、公告、设置、独立84键键盘。设置与键盘复用表现组件，各自保留入口、草稿及输入所有权。
- 设置壳负责窗口/全屏跟随、同步覆盖与按需重排；独立快捷键保留搜索、冲突校验、确认提交和取消。设置及快捷键退回原Esc菜单。
- `rm_client/backend/video/` 与相关工具/测试：图传接入、解码、源切换、重连及退出职责拆分。
- 控制器角度协议与旧链路接入分别封装；既有配置事务、急停和硬件授权边界继续复用。
- 发布脚本复制并校验完整的Endfield资源包，包括设置、键盘素材以及选中的原生DLL。

## 资源判断

必要资源由运行路径、`CURRENT.json`、各包完整性清单及发布脚本共同确认。字体、材质、原版动画、许可证、地图模型和FFmpeg保留。各自独立校验的菜单与Wiki字体不能仅因文件相同而直接删除，否则单独交付的资源包会不完整。

只保留 `CURRENT.json` 指向的原生构建，移出三代未选择的旧构建。约8.4GB解包/编译中间件、生成的Python缓存和临时编译命令已移至仓库外的可恢复归档。工具策略拒绝批量永久删除，因此没有把可恢复清理宣称为磁盘永久删除。归档和个人数据不进入本次源码提交。

执行以下命令核验全部随附资源：

```powershell
$env:PYTHONDONTWRITEBYTECODE='1'
.venv/Scripts/python.exe tools/resource_audit.py --json docs/evidence/hjq-20261026/resource-audit.json
.venv/Scripts/python.exe tools/quality_gate.py
```

## Git可见性与提交

仓库忽略规则已改为显式取消忽略，环境、缓存、本机配置和临时文件都对Git可见。可见性不等于自动暂存：本次通过复核文件清单提交全部项目改动，不上传本机Python环境、个人配置、导入壁纸或凭据。此行为由实际Git测试覆盖。

提交与PR说明区分离线测试、真实Windows界面验证和硬件资格验证。过去按日期存档的证据保留其原始环境和资源标识，不把历史记录中的旧构建当作当前运行依赖。
