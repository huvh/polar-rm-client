# #8 显示文案覆盖清单与验证边界

## 有意保留的英文与原始数据

- 品牌和资产名：POLAR、Jello、Minecraft、效果主题/资源文件名。
- 技术标识和单位：MQTT、UDP、DT7、CC、KMC、PRM1、PTE/LES、协议主题、十六进制命令、端口、IP、FPS、P95、ms、m/s、rad/s、角度、数值。
- 用户拥有的内容：聊天、机器人/目标/地图标记名称、配置/壁纸/文件名、自定义轮盘标签、自定义顶部列标题、别名、按键字符串（包括 `CTRL`、`Ctrl` 等大小写）。
- 未知硬件/第三方错误、日志和诊断原文。已知说明在绘制时汉化，不改用于分类、记录、测试或控制门禁的原值。
- 安全确认口令：`ZERO OBSERVED`、`OBSERVED ON FIXTURE` 等必须保留精确原文，不预填、不代确认。

## 验证方式

- 新增的显示专项直接调用生产方法，比较中英文的非文字像素、矩形、动作/指令载荷、启用状态、缓存失效及原始模型不变。
- 覆盖反复切换语言、用户值恰好与词典键同名、带逗号的未知错误、真实物理键名、对话框取消、所有赛事菜单分支、96 组 DT7 与 168 组水印状态组合。
- Minecraft 使用已有 Unihex 中文字形；英文路径仍使用原位图字体。不替换美术/图标/视频/音效资产。
- Hero 中文离屏画面在支持的最小窗口 1000×620 和 1280×720 实际检查；安全提示和按钮不缺字、不裁切。640×360 低于应用最小尺寸，原有卡片重叠不属于支持尺寸验收。
- CS/BF6 与 Minecraft 融合集成测试使用 GitHub `bd2e590` 的原样 fixture 和逐 Git blob 校验的原版字体。仅作测试输入，未列入补丁的资产变更。
- 没有启动机器人输出、音频播放或真实 GPU/Windows 硬件验收。上述清单是可审计的内置显示范围，不能等价为“所有外部文本/每一像素均已汉化”。
