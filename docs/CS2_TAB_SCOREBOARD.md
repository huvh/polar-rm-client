# CS2 Tab 计分板与 RM 地图联动

## 使用

- 在战斗界面启用 `TacticalMap`，按住 **Tab**（或模块绑定的地图键）。
- 左侧地图与居中计分板同步展开；松开后沿同一条可逆时间线收起。
- 计分板不依赖 `TopMatchBar` 顶部小条的启用状态。
- Tab 展开期间临时隐藏会重叠的 ModuleList、MC 右侧计分板、顶部小条、
  灵动岛和目标指示层；**不会改动这些模块的配置**。收起后恢复。
- Esc、聊天、ClickGUI、Hero 等模态界面拥有更高优先级；失焦会释放保持键。
- 计分板区域拦截鼠标按下、移动、释放及滚轮，不穿透到开火、视角或隐藏按钮。
  地图标记仍走原有坐标变换、输入所有权与后端安全闸门。

## 原版资源，而不是另一张自创表格

2026-10-25 从用户提供的 CS2 目录只读复制了当前计分板的 CSS、XML、TS、
图标和字体。解包发生在独立的 `cs2_tab_reference_20261025`，并验证了资源块。
没有写 CS2 目录、接触 CS2 进程、注入/挂钩，也没有运行游戏内调试工具。

采用原版 classic competitive / with-timeline / no-half-times + set-0 结构：
居中黑色点阵板、左侧 70px 大分数、单排行标题、24px 行、原版 Stratum
字重、蓝/金色与本机行底色。不是之前的百分比宽度、重复队名标题表格。
250ms ease-out 行颜色变化使用当前数值的预热纹理插值，不用白色矩形闪烁。
中间保留原版 100px 战况带、上下 2px 边距和 650px 时间区。RM 适配为经过的
比赛时间与双方装甲血量归零观测；不伪造 CS 回合胜负、炸弹、MVP 或连败补偿。
记录最多 64 条，来源/连接代际/赛季/比赛轮次变更后重置；未知到零不计为击杀。
点击表头可选择排序，已知击杀/血量按数值降序；未知值排在后面。使用原版
250ms ease-in-out 行位置过渡。已知数值变化只对字形使用原版 1s 脉冲，峰值
在 5% 处；不在整张表上叠白色矩形。缺失值不触发提示脉冲。
完整映射与哈希见 `assets/cs2_scoreboard_source/README.md` 和 `provenance.json`。

RM 适配：机器人角色/头像替换玩家身份，HSP 替换为 HP，地图作为左侧附属区。
没有确认的数据显示 `—`；不编造经济、延迟、阵亡、助攻和伤害。2027 未验证
协议仍保持隔离。Steam 举报/点赞/语音/导播功能没有伪装成可用的 RM 控件。

这是 Qt 原生转写，**不是运行 Panorama 引擎**；尚未进行用户游戏内截图的
逐像素/逐帧对拍，不能声称全部引擎细节绝对一致。原版 CSS 的 1s 宽高变化
也没有被误当作打开淡入时间。

## 本轮额外修正

- 高 DPI 地图命中去掉 `combinedTransform()` 中的设备 DPR：Qt 鼠标位置本来
  就是逻辑坐标，不能再套一次 125%–200% 设备缩放。
- 旧的有效个人 CS2 资源包只补齐缺失的新计分板图标/字体，不覆写个人文件。
- Stratum2 的导出文件共享字体族名；现显式指定 Bold / Medium / Bold Condensed /
  Regular Condensed / Mono 字形，避免加载了原字体却仍画成默认 Regular。
- 多色模式图标按 RGB wash 保留内部形状，不再按 alpha 整块染色。竞技模式、
  信号、统计、阵亡 SVG 已在独立目录解包、验证并进入资源清单。
- 既有 Endfield ClickGUI 装配使公开 `jello_clickgui` 的类型发生变化，导致 API
  冻结检查失败。现改为稳定 Jello 外观接口委托 Endfield 绘制策略；命令、
  热点、滚动区和素材预热保持一致。**没有修改历史基线或豁免该断言。**

## 验证范围（2026-10-25）

- 37 套定向回归：37 PASS，0 FAIL/SKIP/INCOMPLETE，源码首尾指纹一致。
  覆盖资源清单、输入、地图契约、MC、2027 隔离、Endfield 设置、API 契约等。
- 上述回归包括 Jello 动画端点、描述换行、全屏滚动、设置键盘 4 套，以及
  竞技时间带、字体字形、图标 wash、脉冲、排序、未知数据与记录边界检查。
- 1280×720 / 1600×900 / 1920×1080 / 2560×1440 与 DPR
  1 / 1.25 / 1.5 / 2：16 组真实生产绘制路径的离屏布局及命中检查。
- 100 次显示进度切换不增加稳定状态的面板/行纹理缓存；面板最多 6 层、
  行最多 64 层。动画期不重新成形文字。
- 编译检查、`git diff --check`。

用户在玩 CS2，本轮最终版本**没有再弹原生测试窗口抢焦点**。离屏绘制不是
GPU/OpenGL 性能验收，不代表已达到指定 FPS，更不是现场实战资格。
独立原生探针 `tools/verify_cs2_tab_desktop.py` 保留供空闲时运行。

离屏复查命令（输出目录必须不存在）：

```powershell
python tools/verify_cs2_tab_offscreen.py --out tmp_tab_preview
```

离屏 QPA 不枚举 Windows 字体，因此预览工具只读加载本机微软雅黑；不打包、
不再分发这个系统字体。实际 Windows 客户端继续使用其系统字体数据库。
