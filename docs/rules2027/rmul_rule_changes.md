### 实现优先级最高的结论

1. **3v3 时长仍为 300s，1v1 仍为 120s；场地仍为 12×8m、5×5m。** 不是扩大场地或延长比赛。[R26 PDF/印16、37、21、39；R27 PDF17/印16、40/印39、23/印22、42/印41，§3、§4、§3.2.1、§4.2，无表]
2. **2026 联盟赛也没有基地/前哨/基地护盾。** 2027 是“200 胜利点 → 600 控制度”和控制区机制调整，不是从“打基地”改成占点。[R26 PDF/印16、35-36 §3/§3.3.4-5、图3-2；R27 PDF17/印16、37-39/印36-38 §3/§3.3.4/§3.3.7、图3-4]
3. **重装是独立角色，官方编号 1；步兵 3、哨兵 7。** 不将 `Heavy` alias 成 `Hero`；开局和安装后的性能必须分开。[R27 PDF17/印16 表3-1；PDF18/印17 表3-2；PDF38-39/印37-38 §3.3.6]
4. **1v1 新增造成弹丸伤害的 50% 回血**，但是没有自动复活、金币兑换目录或 3v3 性能选择。[R27 PDF45/印44 §4.3.1、§4.4；PDF40-41/印39-40 表4-2]
5. **金币只换允许发弹量**：步兵 10金币/10发17mm；重装 10金币/1发42mm；哨兵 750 发不可增，1v1 200 发不可增；无正式付费复活/远程回血/远程买弹价格。[R27 PDF36-37/印35-36 §3.3.3、表3-11/12；PDF22/印21 表3-5续；PDF41/印40 表4-2续]

### 2.1 步兵性能选择的边界

3v3 步兵准备阶段开始后可选底盘 `Power` / `Health`、发射机构 `Burst` / `Cooling`。缺选默认 `Health` + `Cooling`；比赛开始且选择完毕后整局不可更换。四个组合均可由正式表独立组合，不是等级表或技能点表。1v1不适用该性能选择。[R26 PDF/印18 表3-3；R27 PDF19-20/印18-19 表3-4，PDF40-41/印39-40 表4-2]

### 2.2 重装状态机，不是“英雄部署”技能

- 模块化42mm发射机构初始放在**工作台**；重装初始在启动区。两者可在三分钟准备阶段预装弹丸，但初始允许发弹量均为0。[R27 PDF17-19/印16-18，表3-2/3-3]
- **需安装模块化42mm机构，并发射一发被裁判系统正确识别的42mm弹丸，才提升性能。** 不能仅根据时间、金币或接入成功就从100HP切到450HP。[R27 PDF38/印37 §3.3.6，无表]
- 分解为子机器人/柔性电缆连接子系统、合并、安装/拆除机构，均仅能在工作台进行；未成功安装且激活己方补给区时无敌。[R27 PDF38-39/印37-38 §3.3.6；PDF58/印57 §6.2.1.4 R39，无表]
- 全局R38禁止分解而§3.3.6允许重装工作台特例，不能只读R38否定专属机制；也不能外推为允许子系统离开工作台。[同上]
- **未证实**：安装后提升瞬间当前HP是否直接变450、恢复差额还是保留比例；拆除后的降级方式、再次安装的状态保留与首发重复触发。leaf仅储存上限/状态条件，不推算实时当前HP。

### 4.4 1v1新增吸血式回血及表文冲突

## 5. 控制区、控制度、技能点和buff

### 5.1 核心控制机制的实质变化

2026：中央一处控制区，同刻仅一方占领；双方都在区内时先到先得；占领使对方-1胜利点/s；未检测控制区卡后2s占领失效。[R26 PDF/印24-25 §3.2.4、图3-7/8；PDF/印35 §3.3.4及脚注]

2027：红高地、中央、蓝高地**三处**控制区，初始均中立。每一方对每一区均有独立进度，范围0..5：[R27 PDF37/印36 §3.3.4.1，无表；PDF28/印27 图3-10]

| 场景 | 2027进度变化 |
| --- | --- |
| 仅甲方激活，乙方进度=0 | 甲方+1/s，到5即控制 |
| 仅甲方激活，乙方进度>0 | 乙方-1/s，到0失去控制；不能同刻假设甲方也+1 |
| 双方均激活同一区 | 进度暂停，直到仅余一方激活 |
| 双方均不激活非中立区 | 双方进度均-1/s |
| 一方进度降0、双方均无控制 | 该区中立 |

每控制一处使对方-1控制度/s；三处分别结算，所以不能只显示一个“先占者”布尔。占领后离开不是永久锁点。**未证实**：不满5而尚中立时、双方都撤离后的未完成进度如何衰减；规则明确列出的空区衰减限定“非中立”。也不从图形推断任意像素位置即实际RFID激活。
