# 2027 规则年度适配（2026-10-25）

## 范围与入口

本地分支 `feat/rules-2027-20261025` 从包含现有终末地设置/Jello ClickGUI 的
`a6c489344fa59bdaaac1bd6a600a3bd13a2e8b11` 建立，未切换、覆盖或合并主工作区。
未改变液态玻璃 shader、折射参数、字体资源、DT7/0x5A/PRM1 固件 wire。

入口：**System → MatchMode → Season（规则赛季）→ 2027**，然后选择
`RMUC7v7 / RMUL3v3 / RMUL1v1`。终末地设置页和 Jello 设置使用同一注册表。
2026 兼容路径保留；旧完整配置缺少 Season 按 2026 读取，不改磁盘原文件。
2027 是明确选择，不由系统日期、V2 协议名称或官方软件版本推断。

**交付是有来源的规则数据、离线展示和跨年隔离，不是已接通2027官方裁判链路。**
规则预览不运行2026假比赛 tick，不显示模拟敌人、假锁定、旧虚拟护盾或假存活人数。
预览初始血量/金币/时间/控制度是规则值，不是收到裁判数据的证明。

## 通信与实战边界

截至本轮抓取，官方2027协议条目只有标题占位，未取得可审查的附件；这不代表断言
官方在任何位置都未发布。精确抓取时间、响应与哈希见协议审计。

- 旧 `rm2026-v1.3.1 / student preview / rm2026-v2.0.0` 均属2026，不能自动认作2027。
- 2027拒绝新建旧MQTT网络owner、旧下行投影、旧控制/经济/性能发布、旧资格授权，以及
  旧0xA5真实writer；最终enqueue和driver前再次审查年份/epoch，不只隐藏按钮。
- 切年清队列、阶段证据、旧QoS owner和内存资格，回切不恢复Arm。已有owner允许尝试
  固定全零KMC急停；不会为了“发零”新建未审查网络会话，也不伪造串口Stop。
- 队内0x5A、DT7及PRM1是独立固件契约，没有因规则年变更而被重写或自动认证。
  新重装角色与实际固件、装配/姿态/后勤/新空中系统仍需逐能力对齐。
- 正式2027协议、黄金样本、坐标标定、裁判/固件对拍、真车/图传及双人签字未完成。

**Verdict 始终 NOT READY FOR REAL MATCH；离线测试或窗口正常不得变成2027可上场声明。**

## 验证方法

新规则数据、防跨年后端、持久化/UI边界都纳入自动发现的测试文件；使用
`tools/verify_all.py --test <精确suite stem> --json <报告> --log-dir <日志目录>`，
一个aggregate串行运行；报告只对执行的scope负责，不借旧版本全量PASS背书。

`tools/verify_rules_2027_desktop.py --out <新目录>` 额外使用Windows真实OpenGL窗口，
独立临时用户目录和inert transport，检查四种分辨率、三种赛制、设置页、切年和退出。
不打开硬件，不发送运动/开火，不把离屏绘制当真实桌面GPU证据。
本机临时诊断在被忽略的 `tmp_rule_2027/`，不是发布包或现场证据。

后续接入清单及回归结果见 [验证记录](VALIDATION.md)；所有未执行现场测试明确留待验证。
