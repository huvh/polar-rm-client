# RMUC 2027 正式规则相对 2026 V1.5.0 的证据核查

核查日期：2026-10-25。对象仅为超级对抗赛（客户端模式名 `RMUC7v7`），不把高校联盟赛数值混入。页码统一写作 **PDF页/印刷页**，均为1基；本报告两本正式手册的印刷页均比PDF页少1。

## 0. 给集成者的关键结论

- **最终已证实**：2027正式规则已经发布，版本V1.0.0、日期2026-10-15；不是仅有参赛手册或前瞻。
- **最终已证实**：英雄与工程合并为**重装机器人，编号1**；没有独立英雄1号和工程2号。客户端采用新逻辑键 `Heavy`，不保留2027 `Hero` alias，不自动迁移2026用户配置。
- **最终已证实**：420秒、28×15米；重装1、步兵3/4、空中系统6、哨兵7、飞镖系统8、雷达系统9。空中是机库+4台空中机器人的组合系统，不是2026的射击无人机。
- **最终已证实**：基地HP **5000→10000**，前哨站HP **1500→1000**；2026开局150虚拟护盾不能带入2027。2027以“前哨阵地完全控制”决定基地100%防御，新增基地受损的后勤衰减。
- **最终已证实**：重装开局400HP/50W，无可用发射机构；一级装配450HP，二级500HP，三级装配或成功安装模块化42mm发射机构后600HP/50W/热量300/冷却100每秒/弹速16.5m/s。它不是旧英雄近战/远程十级表。
- **最终已证实**：正式规则仍有步兵1至10级、底盘与发射机构选择；未找到通用“性能点/技能加点”制度。不能把这种说法当作2027正式机制。冷却优先9级热量上限特别注意：**2026为114，2027为104**。
- **最终已证实**：初始金币400→800，定期金币50→100、末分钟150→300；补弹价格及两种付费公式主体与2026相同，但回血/复活受后勤系数影响。旧空中支援按秒购买项删除于2027兑换表。
- **最终已证实**：原英雄部署特殊机制取消，`features.hero_deploy=False`。这不等于2027没有视频限制：仍有超热量断图传、飞镖/判罚遮挡，以及基地受损降图传分辨率。
- **未知/待官方补充**：空中冲击有效检测接触时间与面累积冲量，雷达干扰波具体参数。正式PDF本身标“待定”/“后续发布”，不是缺整本比赛规则。

规则事实不证明2027 wire可用。本文和数据leaf不定义MQTT命令编号、串口结构、`command_type/param`、0x5A队内协议或任何输出授权。

### 战场控制（新增独立状态）

S27 PDF97-98/96-97 §5.6.2、表5-20/21：每方有前哨阵地（前哨增益点+中央高地增益点）、基地阵地（基地增益点+堡垒增益点）。前者支持双方完全/临时控制，后者完全控制仅初始拥有方。开局双方各完全控制己方两处阵地。

- 连续激活对方完全控制阵地内任一增益点5秒可变为己方临时控制；不足5秒离开时进度等速回退，不是归零；双方同时激活阵地内增益点时进度暂停。
- 对方不再激活己方被其临时控制的阵地任一增益点连续5秒，恢复己方完全控制。前哨站击毁另可在完全/临时控制间转换，严格按表5-21方向处理，不要写成“打死即自动拿全部控制度”。
- 控制全部2个前哨阵地时，控制度每秒+1；控制全部2个基地阵地时，每秒+3。不是设一个固定 `victory_points` 达标获胜；leaf该字段为None。

### 6.3 回血、价格公式与复活

令t为剩余秒数，L为机器人等级，n为本机器人此前付费立即复活次数。S27 PDF74-77/73-76 §5.3/表5-7，**最终已证实**：

- 远程回血价格：`50+ceil((420-t)/60*20)`，**乘20在ceil内部**。脱战确认6秒后增加当时上限HP的60%，再乘λ，不超上限；6秒内战亡则无效且不退款。
- 立即复活价格：`ceil((420-t)/60)*80 + L*20`，**乘80在ceil外部**。不能给公式卡造固定cost；leaf `cost=None`。
- 基础复活读条：`round_half_up(10+(420-t)/10+20*n)`；实际所需读条按后勤修正除以λ。基础每秒+1，在补给区或己方基地HP**低于4000**时每秒+4。S26阈值是低于2000（PDF77/76），公式主体相同，但2027新增λ后并不完全等价。
- 免费读条复活：保留等级/经验，10%上限HP，无敌30秒、进入虚弱；接触可激活前哨/基地/补给卡后解虚弱，无敌至少满10秒。虚弱下发射锁定，激活增益点不会获得效果。
- 付费复活：满血；**虚弱与无敌3秒**，其后解除；底盘功率翻倍、封顶200W、持续4秒。S26 PDF77/76写付费复活“发射机构立即解锁”，不能带进2027。S27后文还重复出现接卡解除虚弱描述，是条文冗余/边界需官方澄清，不得据此擅改3秒为无限期。
- 补给区普通10%上限HP/秒；比赛4分钟后且脱战25%/秒，均受λ修正。新增完全控制前哨阵地的前哨回血，为此时补给回血速率50%（S27 PDF74/73）。S26无该前哨回血条目。
