# 本地试验：终末地设置与 ClickGUI

分支：`终末地clickgui`，基于 `e889da1`。不合并 main、不推送。

## 呈现来源

- 设置改用原版 GameSettingPanel、全宽 GameSettingItemCellV2 的布局信息。
- 20 张原始图片、原版中文字体、5 条动画曲线随本地资源目录提供；不要求安装游戏。
- 精确的 Sprite rect/border 用于一次裁切、九宫格绘制；不在动画中解包或读盘。
- 全宽灰色行、左侧地形线、图标页签、原版黄色选中图、白色胶囊、开/关、滑块、
  右侧滚动条与黄色焦点描边；不再使用 Jello 白色设置弹窗及弹性放大。
- 进入 25/60 秒、退出 10/60 秒；页签切换使用 gamesetting_change 的透明度曲线；
  开关使用原版 0.2 秒动画的加权曲线。
  加权曲线以 Bezier 时间反解求值，不把 weightedMode 当普通 Hermite。
- 世界背景复用 Esc 已经生成的 GPU 高斯模糊，在场景边界只读取一次；没有有效
  背景或 GL 上下文失效时使用深灰可读背景，不采集桌面、不出现白底降级。

3840×2160 仅为本客户端的源控件密度参考，并非已经证实的 Unity CanvasScaler 参数。
低分辨率正文、分组标题保留至少 16 逻辑像素，中文使用原生字形 hinting，绑定列表
使用高对比文字。真实 Qt 子控件在动画结束后直接显示，避免静态字体
持续缩放采样。不是“所有分辨率逐像素一致”的认证。

## 功能边界

设置项仍然是 POLAR 的真实视频、声音、键鼠、准星、HUD 与游戏功能。不会为了
复刻截图添加不存在的 DLSS/帧生成开关，也不伪造设备负载/显存占用。
没有采集器时顶部读数明确显示“未采集”。保存/恢复默认仍遵循原来的草稿语义，
保存失败会显示错误。Ctrl+F 可显示搜索。

ClickGUI 保留 Jello 六分类、原几何/热点/声音/缩放和时间线，在原 GPU 绘制列表中
加入原版地形纹理、工业分隔与黄色强调。后端、比赛授权、液态玻璃 shader、普通
战斗 HUD 和经济面板不改。原有全屏保护、主窗口关闭和 F12 急停路径保留。
