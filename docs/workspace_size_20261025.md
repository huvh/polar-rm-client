# 本地工作区与主仓库的体积差异

2026-10-25 实测。主仓库是 [lulunomaro/polar-rm-client](https://github.com/lulunomaro/polar-rm-client)，
通过用户指定的 `127.0.0.1:7892` 代理执行 `git fetch --no-tags upstream main`，
比较上游提交 `a22104c48653ae178209af0c4cb289f4ea65ea8c`。
本地 HEAD 为 `10fefb35cf286058f13d50e56862a46fe0bd142e`。
本轮只刷新上游引用，没有合并或修改当前分支历史。

## 两种不同的体积口径

| 口径 | 大小 | 含义 |
| --- | ---: | --- |
| 本地整个目录 | 约 5.33 GiB | 包括 Git 元数据、依赖、用户文件和临时构建 |
| 上游提交内全部文件 | 150.85 MiB | Git tree 中所有文件的未压缩字节 |
| 本地 HEAD 内全部文件 | 138.07 MiB | 本地已提交版本，尚未计入工作区改动 |
| 本地 Git 可见文件 | 237.56 MiB | 仍存在的已跟踪文件，加未跟踪且未忽略的文件 |

同口径比较，本地 Git 可见文件比上游大 **86.71 MiB，约 57.5%**。
“Git 可见”包含尚未暂存的新文件，不代表这些文件已全部选定提交。
本地和上游还有 2 个本地独有提交、7 个上游独有提交，因此两边也不是同一历史基点。
GitHub 仓库存储、ZIP 下载和本地目录分别涉及历史对象、压缩和展开文件，不能直接互比。

## 整个本地目录为什么有数 GiB

| 本地目录 | 大小 | 主要用途 |
| --- | ---: | --- |
| `tmp/` | 3447.64 MiB | Endfield 编译工具链、上游源码、解包及验证中间文件 |
| `.venv/` | 1187.72 MiB | Python、Qt、视觉推理等运行依赖 |
| `user_data/` | 394.28 MiB | 本机用户资源、配置和现场证据 |
| `.git/` | 143.17 MiB | 提交历史和多个分支的 Git 对象 |

按 Git 状态分类，扫描时约 **5074.15 MiB 被 Git 忽略**。
其中也包含 `bin/`、缓存等其他位置的本地文件，不能只用上表前三项相加代替该总数。
忽略文件不会被普通 `git add` 加入提交；Git 元数据也不属于待提交文件。

## 源码与资源本身为什么仍大约多 87 MiB

| 文件范围 | 上游 | 本地 | 差值 |
| --- | ---: | ---: | ---: |
| 文档、报告和验收证据 | 20.48 MiB | 81.82 MiB | +61.34 MiB |
| Endfield 功能、原生实现及其资源 | 58.58 MiB | 96.20 MiB | +37.62 MiB |
| 其他文件 | 71.79 MiB | 59.56 MiB | −12.23 MiB |

Endfield 分类同时覆盖上游的 `assets/endfield_pack/` 和本地迁移后的功能目录，
避免只因为换目录就把整包资产当成额外增加。

主要增长来源：

- Wiki 历史验收目录约 55.82 MiB。仅 7 份约 3.6 MiB 的完整 `quality.json` 就占约 25 MiB；
  多轮保存同一源码树的完整度量会反复记录大量相似内容。
- PNG 总量由约 11.54 MiB 增至 43.20 MiB，包含新增界面资源及验收截图。
- TTF 字体由约 36.84 MiB 增至 45.87 MiB，另外新增约 8.59 MiB 的 WOFF2 字体。
- 原生渲染目录保留多代 DLL 和各自构建记录；增加一个构建会继续保留旧版本文件。

Python 文件合计仅由约 **10.32 MiB 增至 10.44 MiB**。
主要体积增长集中在资源和验收材料，图传封装新增的接口代码占比很小。

另外，未提交的目录迁移在 `git status` 中会显示成“原路径删除、新路径未跟踪”。
`git diff --stat` 尚不包含这些未跟踪文件，单看删除行数、文件数也容易误判实际变化。

本轮没有删除依赖、缓存、字体、DLL 或历史证据。后续若要瘦身，可优先整理重复的完整质量报告、
过往截图及原生构建保留策略；运行依赖和历史验证材料需要分别处理。

机器可读结果见 [workspace_size_20261025.json](workspace_size_20261025.json)。
数据为扫描时的逻辑文件大小，不含目录元数据与磁盘簇占用；临时验证文件可在扫描后继续增长。
