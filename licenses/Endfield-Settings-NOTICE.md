# Endfield settings resources — local presentation trial

The images, font, prefab geometry and animation keyframes in
`assets/endfield_settings/` were imported from local original-resource exports.
`PROVENANCE.json` records their exact source identities, hashes, sprite rectangles
and borders. The client does not open the installed game or load its code.

These game assets remain the property of their respective rights holders.
The repository's code license does not license those assets. This experimental
branch is local only; inclusion here is not a claim of public redistribution
permission. Do not publish a package containing these assets without confirming
the applicable distribution rights, including the bundled original font.

`source_layout.json` includes extracted scalar animation curves. The Python
sampler evaluates their tangents/weights; it is not the Unity engine and does
not claim bit-for-bit Unity float32 execution.
