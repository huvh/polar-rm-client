# UI 音效来源

- `polar_classic/`：POLAR Classic 模块开关反馈音，文件名为 `module_on.wav` 与 `module_off.wav`。
- `liquidbounce/`：本地 LiquidBounce 参考工程的 click 音效，作为可选主题保留。
- `polar_ui/`：从本地第三方参考资源中的 `ping.wav`、`message_rec.wav`、
  `party_invite.wav` 复制并按产品语义重命名，用于模块切换、成功提示与面板过渡反馈。
  真实第三方来源及许可证信息仅在项目的第三方声明中保留。
- `custom/`：用户自行导入的本地音频。

这些文件随客户端发布包原样分发；请在二次分发前核对各参考工程随附的许可证和资源使用条件。
