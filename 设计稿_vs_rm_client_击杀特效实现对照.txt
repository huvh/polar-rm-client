================================================================================
一、改前问题（必须对齐的背景）
================================================================================

改前 VisionKillDetector 只认一条路径：

  敌方 red/blue 亮灯 → 同一轨道连续观测 color/light_state=extinguish
  → extinguish_frames>=3 且 duration>=0.25s
  → 且触发判断写在 for armor in observations 循环内

实战失败主因：
  灯灭后 YOLO 经常「框直接消失」，没有 extinguish 类连续帧
  → 进度不累计、触发分支不跑 → 几乎永不 VISION_CONFIRMED

次要问题：
  - 曝光 hold 时清空 extinguish_frames（击杀瞬间 AE 变暗最易误清）
  - 颜色仍报 red/blue 但灯已暗 → 每帧当 lit 重置进度
  - LocalTargetSelector 丢检 0.35s/3 帧就 track_id++ → lit 历史作废


================================================================================
二、改后总体行为（对齐目标语义）
================================================================================

必须先有敌方「确认亮灯」历史（lit_at），然后 **任一路径** 可确认击杀：

  A. classic extinguish
     detail = "vision_confirmed_lamp_off"
  B. dim lamp（颜色可能仍是 red/blue，但 light_strength 持续很低）
     detail = "vision_confirmed_dim_lamp"
  C. miss-to-kill（亮灯后短时 detections 中不再出现该目标）
     detail = "vision_confirmed_miss_after_lit"

仍不触发：
  - 从未亮过
  - 友军灯色
  - predicted=True
  - conf < 0.70
  - 已 _eliminated 且未重新确认亮灯

仍走原管线：
  detector.process → list[CombatEvent]
  → polar_app.accept_combat_event → kill_fx.trigger
  （UI 层无需改即可消费新 detail）

3.2 VisionKillDetector 类常量（改后，全部在类体上）

  # 经典 extinguish
  EXTINGUISH_MIN_FRAMES = 3
  EXTINGUISH_MIN_DURATION = 0.20      # 改前 0.25

  # 过暗辅助
  DIM_STRENGTH = 0.22                 # <= 此值为 dim
  LIT_STRENGTH = 0.40                 # >= 此值为确认亮灯
  DIM_MIN_FRAMES = 3
  DIM_MIN_DURATION = 0.20

  # 丢检确认
  MISS_MIN_FRAMES = 4
  MISS_MIN_DURATION = 0.28
  LIT_MIN_HISTORY = 0.15              # 亮灯至少存在这么久才允许确认
  MISS_MAX_AFTER_LIT = 2.5            # 亮灯过久再丢，偏遮挡，不 miss-kill

  # 曝光
  EXPOSURE_DELTA = 0.28               # 改前 0.20
  EXPOSURE_HOLD = 0.20                # 改前 0.40；且策略改为 Pause 不清零

  TRACK_TTL = 8.0
  CONF_MIN = 0.70

3.3 保留的公开 API（签名未破）
--------------------------------------------------------------------------------

  VisionKillDetector()
  .reset()
  .target_identity(armor) -> str      # 优先 target_id，否则 armor_id
  ._track_key(armor) -> f"{identity}:{label}"
  .is_extinguished(armor) -> bool
      color=="extinguish" OR light_state in (extinguish,extinguished,off,dead)
  .is_suppressed(armor) -> bool       # identity in _eliminated
  .process(observations, *, alliance, frame_luminance=None, frame_token=None, now=None)
      -> list[CombatEvent]
  .last_status: str                   # HUD 用

--------------------------------------------------------------------------------
3.4 新增内部方法
--------------------------------------------------------------------------------

  _reset_extinguish_progress(track)
      清 extinguish/dim/miss 的 start 与 frames

  _mark_lit(track, *, target_identity, now, frame_token, victim_id, color, strength)
      - _eliminated.discard(identity)
      - lit_at=now, triggered=False
      - 记录 identity/victim/color/strength/frame_token
      - _reset_extinguish_progress
      - status=LIT_TRACKED

  _count_progress(track, *, now, frame_token, exposure_hold, kind)
      kind in ("extinguish", "dim")
      if exposure_hold:
          status=EXPOSURE_HOLD; return   # 暂停，不清零
      fresh_frame = frame_token is None or track.last_frame_token != frame_token
      extinguish 分支：
          设 extinguish_start；fresh 则 frames++
          清 dim 与 miss 进度
      dim 分支：
          设 dim_start；fresh 则 frames++
          清 miss 进度

  _emit(track, *, now, detail) -> CombatEvent
      triggered=True
      _eliminated.add(identity)
      status=VISION_CONFIRMED
      return CombatEvent(
          "elimination", "vision", True, now,
          victim_id=track.last_victim_id,
          detail=detail,
      )

  _finalize_tracks(now, *, vision_frame_advanced) -> list[CombatEvent]
      对每条 track（未 triggered、有 lit_at、不在 eliminated）：
        若 lit_age < LIT_MIN_HISTORY: skip

        1) extinguish_frames>=3 且 duration>=0.20
           → emit detail=vision_confirmed_lamp_off

        2) dim_frames>=3 且 duration>=0.20
           → emit detail=vision_confirmed_dim_lamp

        3) not seen_this_frame:
           - 仅当 vision_frame_advanced 时 miss_frames += 1
             （避免 UI 60fps 重复消费同一视觉快照误杀）
           - 若 miss_start 未设则设 now
           - miss_ok = frames>=4 OR duration>=0.28
           - 且 lit_age <= 2.5
           → emit detail=vision_confirmed_miss_after_lit

        4) seen_this_frame:
           清 miss_start/miss_frames（保留 extinguish/dim 进度）

--------------------------------------------------------------------------------
3.5 process() 主流程（改后，必须按此顺序实现）
--------------------------------------------------------------------------------

  now = perf_counter() if now is None else now
  last_status = "NO_DETECTION"

  # 轨道 TTL
  保留 last_seen_at 在 TRACK_TTL 内的 tracks
  所有 track.seen_this_frame = False

  # 视觉帧是否推进
  vision_frame_advanced = (frame_token is None) or (frame_token != _last_scene_frame_token)

  # 曝光：仅在视觉帧推进且有 luminance 时更新
  if frame_luminance is not None and vision_frame_advanced:
      if last_luminance 存在 and |Δ| > EXPOSURE_DELTA:
          _exposure_hold_until = now + EXPOSURE_HOLD
      更新 last_luminance、_last_scene_frame_token
  elif vision_frame_advanced:
      只更新 _last_scene_frame_token

  exposure_hold = now < _exposure_hold_until
  alliance_l = alliance.lower()

  for armor in observations:
      if predicted: continue

      color = color.lower()
      light_strength = float(...)
      light_state = light_state.lower()
      extinguished = is_extinguished(armor)
      lit_color = color in (red,blue) and not extinguished

      strength_known = light_strength > 1e-6
      dim_by_strength = lit_color and strength_known and light_strength <= DIM_STRENGTH
      confirmed_lit = lit_color and (
          light_strength >= LIT_STRENGTH
          or (not strength_known and light_state not in extinguish类)
      )
      # strength==0 常见于未采样：颜色红/蓝且非灭灯态 → 当确认亮灯
      hysteresis = lit_color and not dim_by_strength and not confirmed_lit

      if not lit_color and not extinguished:
          INVALID_LIGHT_STATE; continue

      if lit_color and color == alliance_l:
          # 友军：解屏蔽，不进敌方轨道
          _eliminated.discard(identity); OWN_TEAM_FILTERED; continue

      if confidence < CONF_MIN:
          LOW_CONFIDENCE; continue

      track = tracks.setdefault(track_key, _VisionTrack())
      更新 last_seen_at, seen_this_frame=True, target_identity,
            last_victim_id=armor_id, last_color, last_light_strength

      if confirmed_lit:
          _mark_lit(...); continue

      if identity in _eliminated:
          ELIMINATED_SUPPRESSED; continue

      if lit_at <= 0:
          NO_LIT_HISTORY; 清进度; continue

      if hysteresis:
          # 中间带 0.22~0.40：保持 lit 历史，不重置灭灯进度
          HYSTERESIS; continue

      if extinguished:
          _count_progress(..., kind="extinguish")
          status: EXPOSURE_HOLD / REFLECTION_IGNORED / MODEL_CONFIRMED / WAITING_FRESH_FRAMES
          continue
          # 注意：model_extinguish 且 strength>0.38 仍累计（抗反光），status=REFLECTION_IGNORED

      if dim_by_strength:
          _count_progress(..., kind="dim")
          status=DIM_TRACKED（非 hold 时）
          continue

      INVALID_LIGHT_STATE

  return _finalize_tracks(now, vision_frame_advanced=vision_frame_advanced)

--------------------------------------------------------------------------------
3.6 与改前关键差异对照表
--------------------------------------------------------------------------------

  点                    | 改前                              | 改后
  ----------------------|-----------------------------------|----------------------------------
  触发位置              | for 循环内直接 emit               | 帧末 _finalize_tracks
  丢检                  | 不处理                            | miss-to-kill 主路径之一
  过暗                  | 无；非 extinguish 且 strength>0.38 清零 | dim 累计；中间带 hysteresis
  确认亮灯              | 任意 red/blue 非 extinguish       | strength>=0.40 或 strength 未知
  曝光 hold             | 清空 extinguish 进度              | 暂停累计，保留 frames
  曝光阈值              | Δ>0.20 hold 0.40s                 | Δ>0.28 hold 0.20s
  extinguish 时长       | 0.25s                             | 0.20s
  BRIGHTNESS_BLOCKED    | 有，清空进度                      | 删除该硬清零路径
  detail 种类           | 仅 vision_confirmed_lamp_off      | 三种 detail（见上）
  miss 计数             | 无                                | 仅 vision_frame_advanced 时 +1

--------------------------------------------------------------------------------
3.7 last_status 取值（HUD：KILL VISION | xxx）
--------------------------------------------------------------------------------

  NO_DETECTION, INVALID_LIGHT_STATE, OWN_TEAM_FILTERED, LOW_CONFIDENCE,
  LIT_TRACKED, NO_LIT_HISTORY, HYSTERESIS, EXPOSURE_HOLD,
  DIM_TRACKED, MISS_TRACKED, ELIMINATED_SUPPRESSED,
  MODEL_CONFIRMED, WAITING_FRESH_FRAMES, REFLECTION_IGNORED,
  VISION_CONFIRMED

  仍用优先级字典：只允许 status 升级或同级覆盖（_set_status）

      - item.color == "extinguish" or self.color == "extinguish"
      - item.light_strength <= 0.22

  匹配失败才 track_id += 1 并按 conf 选新目标
  匹配成功（亮→灭）：**不因颜色变化单独 +1 track_id**

  平滑 center 0.38*new + 0.62*old；更新 name/color；missed=0；last_seen=now
  return (candidate_index, track_id)

八、伪代码（完整可照抄）
--------------------------------------------------------------------------------

  # 每帧 process(observations, alliance, frame_luminance, frame_token, now)

  mark all tracks seen_this_frame=False
  vision_frame_advanced = token changed
  update exposure_hold if advanced and |Δlum| > 0.28 → hold 0.20s (Pause policy)

  for armor in observations:
      skip predicted / low conf / invalid color
      skip own alliance lit colors
      track = get_or_create(identity:label)
      track.seen_this_frame = True
      record victim_id, color, strength

      if confirmed_lit:           # strength>=0.40 or strength unknown
          mark_lit; clear progress; continue
      if eliminated: continue
      if never lit: continue
      if hysteresis: continue     # 0.22 < strength < 0.40
      if extinguish class:
          count extinguish (pause if exposure hold); continue
      if dim strength:
          count dim (pause if exposure hold); continue

  for track in tracks:
      if extinguish ready: emit lamp_off
      elif dim ready: emit dim_lamp
      elif not seen and miss ready and lit_age in [0.15, 2.5]:
          emit miss_after_lit   # miss_frames only if vision_frame_advanced
      elif seen:
          clear miss counters

  return events
